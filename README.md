# 전통문화 Auto Pets (6학년 영어 11단원)

선생님이 방을 만들고, 학생들이 방 번호로 들어와 영어 문제를 풀고 전통문화 친구를 모아 서로 대결하는 수업용 게임입니다.

## 접속 주소
- 학생: `https://(주소)/` → 타이틀의 **게임 시작** → 방 번호·이름·캐릭터 선택
- 선생님: `https://(주소)/teacher` → **확인**을 누르면 4자리 방 번호가 나와요

## 수업 진행 순서
1. 선생님 화면에서 방을 만들고 방 번호를 칠판에 적어 주세요.
2. 학생들이 다 들어오면 **자동 팀 배정**(1라운드 상대) → **전투 시작**을 누르세요.
3. 학생은 문제를 풀고(정답 = 코인 +3·체력 +1, 번개 정답 = 코인 +1·공격 +1) 상점에서 친구를 모은 뒤 **전투 시작**을 눌러요.
4. 1라운드 대결이 끝나면 **준비를 먼저 마친 학생끼리** 자동으로 만나서 대결해요.
   - 체력이 같아 비기면, 이번 라운드에 문제를 더 많이 → 더 빨리 맞힌 학생이 이겨요.
   - 홀수라 혼자 남으면 다른 학생의 최근 팀 기록과 대결해요(선생님의 **자동 전투** 버튼은 기다리는 학생을 바로 대결시켜요).
5. 정해진 라운드를 마치면 학생 화면에 우리 반 순위가 나와요. **결과 저장**으로 엑셀(CSV)로 내려받을 수 있어요.

학생이 새로고침하거나 와이파이가 끊겨도 같은 기기로 다시 열면 이어서 할 수 있어요.

## 문제 바꾸기
선생님 화면 **문제 관리**에서 수정·추가하거나, 한 줄에 한 문제씩 붙여넣어요.
`질문 | 정답 | 오답1 | 오답2 | 오답3 | 그림 | 힌트` (그림: song, gat, hanbok, hanji, kimchi, tuho / 빈칸은 `___`)

## 원어민 음성
- 기본 문제 36개의 모든 문장은 자연스러운 원어민(신경망) 음성 파일로 미리 만들어 `public/audio`에 넣어 두었어요.
- 새로 넣은 문제는 서버가 Microsoft Edge 원어민 음성(Ava)으로 만들어 저장해요. 그것도 안 되면 기기에서 가장 자연스러운 영어 목소리를 골라 읽어요.

## Render에 올리기
1. 이 폴더를 GitHub 저장소에 올려요.
2. Render → New → Web Service → 저장소 선택 (render.yaml이 있어 설정이 자동으로 채워져요)
   - Build: `npm install` / Start: `npm start`
3. 무료 요금제는 한동안 접속이 없으면 잠들어요. 수업 시작 5분 전에 선생님 화면을 한 번 열어 깨워 주세요.

## 내 컴퓨터에서 실행
```
npm install
npm start
```
→ 선생님 `http://localhost:3000/teacher`, 학생은 같은 와이파이에서 `http://(선생님 컴퓨터 IP):3000`
